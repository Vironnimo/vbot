# v0.4.49 - 2026-11-25

## Before you update

- **Agent permissions** — Agents and Team members that inherit their Permission Rules now use the Restricted profile unless you configured a different shared default. If an Agent needs Full Access, set it on that Agent before updating, or choose it under Shared defaults for all Agents that inherit their rules.
- **Project Teams** — A Team member whose repository definition and vBot overrides both omit a Tool list now follows the shared Tool selection. With the shipped defaults it loses `terminal`, `status`, `show_widget` and `portal`. To keep a required Tool, add it to the member's definition or override, or include it in Shared defaults.
- **Software Factory** — Concurrent Runs now have one limit across all Factories. The default changed from two to unlimited, and per-Factory and per-member capacities no longer apply. To keep a cap, set a positive WIP limit in the Extension settings before updating. After the update the setting is called **Max concurrent runs**.

## Highlights

- Set Tool access and Skills once under Shared defaults. Agents that inherit either setting follow later edits automatically. New Swarms can inherit both settings too. Existing Agents and Swarms keep their explicit selections. You can also choose a named Permission Profile for one Session from the Chat composer.
- Chat can recover when a Provider reports that a conversation has outgrown its context window. If Compaction is enabled, vBot can shorten the conversation and resume the same Run.

## Improvements

- **Chat** — Hover over a Run to see how many Model responses and Tool calls it used. Compare cache hit rates for the Session, latest Run and latest iteration.
- **Providers** — vBot learns which request options a Model accepts and skips exhausted accounts until their reported quota resets. OpenCode Go and Zen respect workspace-specific Model access, and Usage distinguishes balance charges from included Go usage.
- **Web Tools** — Choose a backup search service for temporary failures. Web fetch remembers which method worked for a page, and website watches resume after temporary failures while respecting the site's retry interval.
- **Updates** — Interrupted package downloads can resume.
- **Video** — After a restart, vBot can retrieve a video job already accepted by the Provider and deliver it to the original Session without paying for a second generation.
- **Software Factory** — Open the Leader's Session from the dashboard, edit a Specialist's role and instructions from the Team view, and dismiss a failed Job Run once you have reviewed it.
- **Extensions** — Remote MCP connections can negotiate HTTP or SSE automatically. Extension API 42 exposes the shared Tool and Skill defaults through the host catalog.

## Fixes

- **WebUI and voice** — Uploads and recordings stay with the draft where they started. Settings reconcile interrupted saves after reconnecting. Microphone capture can recover from a rejected format, and Desktop dictation splits oversized uploads without repeating audio.
- **Channels** — Telegram Run buttons keep working after group migration, Discord preserves the original format of smaller attachments, and email accounts that reject IMAP IDLE receive mail by polling.
- **Shell** — PowerShell reports the exit status after control flow more reliably. Shell calls honor explicit wait times, retain captured output if supervision fails, and protect Windows command resolution under restricted permissions.
- **Recall and Sub-Agents** — Recall remembers compatible embedding requests per Provider account. A completed Sub-Agent answer stays available until the Parent Session stores it.
