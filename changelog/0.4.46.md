# v0.4.46 - 2026-11-20

## Before you update

- **Providers** — The headless Google Antigravity subscription connection has been removed. Select another Model for any Agent or Session configured to use it before updating.
- **CLI** — After installing this version, an interactive `vbot update` prompts for confirmation when a newer release has pre-update notices. Add `--yes` if the command needs to proceed unattended in an interactive terminal.

## Highlights

- Chat Tool rows preview images, video and audio. Expand a row to see its results and, for shell calls, copy the full command.
- Desktop wakeword commands can run configured Home Assistant actions directly. You can choose whether to tell your Agent what happened.
- The WebUI shows what changed before you update and lets you reopen the installed release notes from Settings.

## Improvements

- **Projects and Skills** — Create files and folders in the path picker, select multiple paths where supported, and install several Skill packages in one batch.
- **Chat** — Tool rows use category icons, show a spinner while running and spell out failures. Reasoning rows draw less attention, and the dark chat background is slightly lighter.
- **Settings** — Interface layout now lives under Appearance, credentials are grouped under Secrets, and embedded Extension settings fit their panels.
- **Statistics** — Usage limits in the overview line up by reset window.
- **Tools** — Search a saved web page for several terms in one call, with shared excerpts and match counts for each term.
- **Extensions** — The browser SDK adds an embedded settings component. The Python Provider SDK no longer accepts `antigravity` as a wire protocol.

## Fixes

- **Sessions** — Results get unread markers when they finish out of sight. Viewing a result clears the marker without clearing newer results that arrive in the meantime.
- **Shell** — Chat preserves literal output and displays the final output, diagnostics and stop outcome. On Windows, PowerShell startup and protected directories have stronger safeguards.
- **WebUI** — Chat collapse rails follow the pointer so their controls are easier to reach.
