# v0.4.48 - 2026-11-25

## Before you update

- **Software Factory** — Jobs replace Workflows, Cards and Kanban tasks. Before updating, finish any work still on the old board and save the prompts, schedules and webhook configurations you want to reuse. The old records stay in the database. To run that work again, create Jobs and reconnect their triggers after the update.
- **Factory integrations** — Update automations and Agent Tool selections that use `factory_card` or Card and Workflow operations. The new `factory` Tool can manage Jobs and Specialists across Projects. Review which Agents should have it. The `max_waiting` setting and per-Card budgets no longer apply.

## Highlights

- Run a Software Factory Job on demand, on a schedule or from a webhook. Assign it to the Project's Leader or a Specialist, follow it from the dashboard, and reply in its Session when it needs your input.
- You can approve a restricted Agent's request to read a specific path in vBot's data folder. Credentials, Agent configurations and server access records remain protected.

## Improvements

- **WebUI** — Management lists use the same row action menus as the Session list.
- **Editing** — When an edit fails to match a long line, the Agent sees where the text first differs. File Tools also suggest similar filenames for missing paths.

## Fixes

- **Attachments** — Agents can reopen files delivered to their Session on later Runs, including after a server restart.
- **Computer Use** — A batch directed at a window stops if focus moves elsewhere. The Stop control stays visible while Chat updates.
- **Shell and permissions** — Shell results identify which command failed, background completions retry delivery after a restart, and restricted PowerShell reads recognize approved paths more reliably.
- **Web Tools** — Web search respects requested URL paths, and web fetch recognizes pages whose only content redirects to another page.
- **Desktop Voice** — Escape can cancel dictation during recording cues, and Live voice stays on hold until the cue ends. Cancelling speech interrupts retry waits, and a failed wake-word listener releases its microphone and reports the error.
- **Providers** — OpenCode Go and Zen route Models through the API their catalog specifies. Perplexity context embedding Models on OpenRouter now receive the input type they require for Recall queries and indexing.
