# v0.4.47 - 2026-11-22

## Before you update

- **MCP** — If you use the MCP Extension, keep a data snapshot from before the update. On its first activation after the update, the Extension encrypts existing recovery data in its `tasks` database. Older vBot versions refuse to open the migrated database. Downgrading requires restoring the pre-update snapshot, which discards everything written to that database since the snapshot.
- **Security** — Update promptly if you run a shared server or use Agent Secrets. This release tightens Session isolation and access checks for MCP, Agent Secrets, Channels, Desktop Computer sharing and permission approvals.

## Highlights

- Search messages in the displayed Session and jump to a match directly from Chat.
- The WebUI opens Chat sooner, and the composer becomes available as soon as the history loads. Runs also start with less delay and can transcribe several audio attachments concurrently.
- WebUI and terminal setup let you start chatting after selecting a Provider and Model, with Skills, Extensions and web search available as optional setup steps.

## Improvements

- **Chat** — Compact Tool rows show key arguments and preview returned media while a Run is still working. If sending fails, you can retry from the composer with your draft intact.
- **WebUI** — Row menus make Agent and Project actions easier to reach. External history import now lives under Settings → Memory.
- **Providers** — The Connect dialog checks API keys and reports whether the Provider accepted the key. Endpoints that cannot verify a key still allow saving it as unverified.
- **Performance** — Terminal rendering, Recall, Calendar, Statistics and the Factory and Swarm dashboards do less work when loading or updating large views.
- **Extensions** — API 41 adds owner-bound encrypted storage, registration-checked routing to shared Computers and a way to save Permission Profile assignments safely.

## Fixes

- **Chat and Sessions** — The browser Back button restores the previous chat selection, removing a Queue item refreshes the queue, and transcripts remain available when their recordings are missing. Forked Sessions retain additional saved history fields.
- **Runs** — Failed Compaction preparation lets the Run continue, and Chat reports the final Compaction outcome. Stopping all work keeps the Queue paused until cancellation settles.
- **Tools** — File reads keep surrounding lines across pages, web fetch preserves matching excerpts within output limits, and Terminal resizes finish cleanly during cancellation.
- **Providers** — Malformed responses keep their error details private and preserve stored sign-in credentials. Gemini cache usage stays unknown when the Provider does not report it.
- **Desktop** — Removing an unknown server keeps sign-in for the selected server. Shared Computer requests and grants stay with the verified installation and selected server.
- **Channels and automation** — Telegram albums stay within their own chat. Group messages keep submitted secrets out of stored history and Runs. Rotating a webhook secret retires receipts tied to the previous key.
- **Installation and recovery** — Linux installers report incomplete installations, rollback prevents server startup while restoring data, and snapshots and archived Projects recover more reliably.
