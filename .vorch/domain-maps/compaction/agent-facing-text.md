# Compaction Agent-facing Text

Why each sentence of the Agent-facing text the Compaction domain owns exists: the Compaction instructions in `resources/prompts/compaction.md`, `compaction-manual.md`, `compaction-continuation.md` and `compaction-continuation-manual.md`, and the checkpoint texts `COMPACTION_REFERENCE_PREFIX`, `COMPACTION_USER_QUOTE_PREFIX` and `SKILL_COMPACTION_GUIDANCE` in `core/compaction/compaction.py`. No reasons are recorded yet for the existing sentences; add a row whenever you change or add one. Rules for this file: `.vorch/workflows/domain-map-workflow.md` -> Agent-facing text.

| Text | Reason |
|---|---|
| `[... {omitted} characters omitted from this Tool result for Compaction ...]` | Marks clipped Tool observations in a rescue-only request, preserving head and tail without presenting their concatenation as complete output. |
| `Some older conversation exchanges were omitted because the Provider rejected the Compaction request's size.` | Tells the Summary Model that the rescue view no longer contains all exchanges it would otherwise assume it summarized. |
| `Summarize only the remaining evidence; do not infer omitted details.` | Prevents filling missing older exchanges with invented facts after whole-exchange omission. |
| `Some older conversation exchanges were omitted from this summary's input after the Provider rejected its size.` | Deterministically records incomplete source coverage in a successful checkpoint; the Summary Model cannot silently omit this limitation. |
| `The original Session history is unchanged.` | Distinguishes summary-input omission from deletion of the canonical conversation, which remains available for later recall. |
| `If a <user_instruction>...</user_instruction> block is present, ...` (all four instruction files) | Announces the block that `_build_compaction_instruction` wraps around the text the user gave `/compact`; the authority marker tells the Model the text comes from the user for this one compaction. Continuation uses the same wrapper, so the announced block is what the Model actually sees. |
| `Answer with this text only and call no Tools: a Tool call fails the checkpoint.` | The Compaction request keeps the Tool definitions and acceptance rejects any Tool attempt; mid-task, the likeliest wrong turn is to continue the task with a Tool call, which aborts the Compaction. Not yet seen in a logged failure. |
| `Every detail required to continue seamlessly must be in your output.` (Continuation) | The output replaces the whole conversation. "Nothing else is retained" was removed because notes outside the request and the activated Skill names are retained too. |
| `Preserve exact file paths, symbol names, command names, and error strings that remain relevant.` (Continuation) | Without the relevance qualifier the Model dumps every path seen, which inflates the checkpoint. |
| `Context checkpoint: the summary below records the conversation and task state up to a cutoff. ...` (`COMPACTION_REFERENCE_PREFIX`) | Read on every request after a summary. It says the summary ends at a cutoff, that later messages can correct it, and not to restart or repeat completed work. The quote sentence lives only in `COMPACTION_USER_QUOTE_PREFIX`. `_summary_body` still strips the previous `[CONTEXT COMPACTION]` wording so older checkpoints are cleaned when summarized again. |
