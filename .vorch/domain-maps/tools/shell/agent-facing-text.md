# Shell and background_tasks Agent-facing text

Read for writing, changing, removing or reviewing any text an Agent sees from `bash`/`powershell` or `background_tasks`, or for the evidence behind one. Behavior, contracts and tests stay as described in `tools/shell.md`.

Failure modes F1-F6: `tools.md` -> Terms. Evidence labels: "usage analysis" and "interface audit" are the 2026-10-04 studies (Sessions and scenario drivers; counts only); "shell review" is the 2026-10-05 review of the shell side, each finding reproduced with the real pwsh 7 on Windows; "eval round 1" and "terminal review" are defined in `tools/terminal.md` -> Agent-facing text. "Usage 2026-10-11" is the study behind the one-shot rebuild: 45,465 shell calls (2026-07-21..10-11) with 0 inputs typed into a command and about 20 calls that touched a prompt, none needing one; foreground median 0.5-1.4 s, 99th percentile 44-57 s, 0.6-1.1 % outlived 90 s; of 806 background commands of the `process` era about 50 % got no follow-up, 15-17 % an Agent kill (servers the main targets) and 4-10 % polling, and before a ready wait existed Agents checked readiness themselves with HTTP probes (about 100 calls); Agents detached servers with `Start-Process` in 526 commands (72 Sessions) and only 37 of 69 such Sessions stopped them; only one Model family sent `timeout` in milliseconds (319 calls); `mode` appeared in 0.1-18 % of calls by period. "Reference harnesses": Claude Code, Codex, opencode, pi, hermes and openclaw all give one-shot commands null or closed stdin; Claude Code waits 2 minutes by default and at most 10, has `run_in_background`, a notification on exit and `BashOutput`/`KillShell` (later `TaskOutput`/`TaskStop`). "Review A" to "Review G" are the reviews of the one-shot rebuild before its merge (2026-10-12), each finding reproduced with a probe or read from the code; "B5" is finding 5 of review B. "Swarm review 2026-10-12" is the review of the shell calls of one Swarm run: every hint change was replayed over its 251 failed commands, and a change was kept only where each changed hint was the intended one. Texts show the Windows variant with every neighbor Tool callable unless noted, and are the same at every Session depth; `<id>`, `<path>` and `N` are filled with real values.

Left out of the description on purpose (review 2026-10-08, kept in the one-shot rebuild), because a result or hint covers each at the moment it matters: the move to the background and the delivery (the results say it when it happens); that commands get no input and have no terminal (interactive attempts are about 0.04 % of calls, Usage 2026-10-11; the failure hints carry the boundary when it applies, and `terminal`'s own description draws it); editor and credential prompts (the `GIT_EDITOR` stub and `GIT_TERMINAL_PROMPT=0` fail with the fix).
