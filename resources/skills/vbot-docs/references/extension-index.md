# Extension usage guides

The running server fills this reference with the Extensions it discovers and links to their usage guides. This source copy has no instance-specific catalog.

Use `vbot extensions list` to inspect the running server's Extensions and load status. For a loaded Extension, `vbot extensions operations <name>` lists its operations and `vbot extensions run <name> <operation> --help` describes one operation's arguments; replace the placeholders with the returned names.
