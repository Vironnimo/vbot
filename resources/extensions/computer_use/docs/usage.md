# Computer Use setup

The `computer_use` Extension lets an Agent operate the selected Computer's Windows desktop with the user's real mouse and keyboard. The Computer can be the vBot server or a connected Desktop app sharing Computer Use; it needs a signed-in Windows desktop. Its three opt-in Tools are `computer` (screenshots, zoom, clicks, typing, keys), `computer_batch` (several actions in one call) and `computer_apps` (list apps and displays, bring an app to the front, request approval, hand the computer back). Enable them in the Agent's Tool settings; a Project Agent also needs them in the Project's `--allowed-tools` and its Tool override. The Extension's `computer-use` Skill teaches how to work with them.

By default, an Agent with these Tools operates every application without asking. The Extension setting `ask_per_app` ("Ask before each app") makes the user approve applications per Session instead: the Agent asks with `computer_apps` `request`, the user answers in the vBot app's request dialog, and the Agent waits up to five minutes. In that mode, screenshots show unapproved apps as gray boxes, input goes only to approved apps, and approvals end 30 minutes after the Session's last Computer Use call or when the server restarts or the Extension reloads. Applications running as administrator receive no input in either mode.

While an Agent controls the desktop, an orange frame lines the screens, from its first desktop call until it hands the computer back with `computer_apps` `release`, its reply ends, or two minutes pass without a call. The user stops it at any time with the Stop control in the Chat composer or by pressing Esc twice within 600 ms; the Agent cannot take the computer again until the user's next message. Input already delivered cannot be undone.

Inspect the configuration with `vbot extensions show computer_use`; set the per-app approval switch with `vbot extensions set computer_use ask_per_app true` or `false`, as requested by the user. These CLI commands configure desktop access; desktop actions themselves use the Computer Use Tools.

Inspect desktop control through `vbot extensions run computer_use control --action status`. To stop the active control when the user asks, use `control --action stop --control-id <control-id>` with the id that status returned, preceded by `vbot extensions run computer_use`. `respond` relays the user's answer to an access request; its `--help` describes the input, and `--stdin` carries the JSON. An Agent does not approve its own access request.
