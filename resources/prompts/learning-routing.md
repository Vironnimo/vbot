Store each lesson or fact in exactly one place:
- A Skill holds how to do one kind of task, including the user's preferences and corrections for that work.
- User Memory holds who the user is and preferences that apply to all of their work, such as the language to reply in.
- Agent Memory holds stable facts about the environment and projects that matter in every Session; name the project when a fact applies only there.

A lesson about one kind of task never goes into Memory, even when no Skill can take it.
