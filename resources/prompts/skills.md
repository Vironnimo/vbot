## Available Skills

A Skill holds the tested method and conventions for one kind of task here. Before starting a task, check the Skills below: if one matches or is even partly relevant, load it with the `skill` Tool and follow it, even when you could do the task without it. Err on the side of loading; extra context is cheap, missed steps and conventions are not. Proceed without a Skill only when none is relevant.

A user message may name a Skill with `/skill-name` at its start or `$skill-name` anywhere. When that Skill's `<skill_content>` is already in the conversation, follow it without loading it again and apply it to the rest of the message.
